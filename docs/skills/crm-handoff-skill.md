# CRM Handoff Skill

## Purpose

Convert messy client communication into structured CRM updates, follow-ups, account memory, and team handoffs.

## What It Does

- Extracts next steps from calls, emails, notes, and status changes.
- Identifies the owner, due date, account, and recommended CRM update.
- Separates activity notes from field changes.
- Requires review before sensitive CRM writes.

## Why It Matters

Revenue systems need more than a transcript summary. This skill turns communication into structured operating memory while preserving approval boundaries around CRM state.

## Outputs

- CRM-ready note
- Suggested field updates
- Follow-up task
- Owner routing
- Review-required fields
