# Public Archive Skill

## Purpose

Turn selected work, articles, documents, repositories, and media into a curated public surface.

## What It Does

- Separates public-safe material from private operating context.
- Groups work by articles, repositories, documents, media, and skills.
- Adds short context so the archive is not just a list of links.
- Preserves outbound links without mirroring private source material.

## Why It Matters

A useful public archive should show the shape of the work without exposing raw notes, private client data, or unfinished internal systems.

## Outputs

- Archive item
- Short description
- Public-safe context
- Link grouping
- Review status
