# Airtable Schema Template

## Companies

Fields: Company ID, Company Name, Domain, Description, Industry, Employee Count, Funding Stage, Funding Amount, Tech Stack, LinkedIn URL, Source, Discovered At, ICP Segment, ICP Score, Pipeline Stage, Enrichment Status, Enrichment Date, Enrichment Notes, Owner.

## Contacts

Fields: Contact ID, Company, First Name, Last Name, Email, Title, Phone, LinkedIn URL, Enrichment Confidence, Source.

## Review Queue

Fields: Review ID, Company, ICP Segment, Draft Summary, Suggested Actions, Status, Reviewer, Reviewer Notes, Created At, Reviewed At, Write Payload, Write Result.

## Activities

Fields: Activity ID, Company, Activity Type, Timestamp, Summary, Source, Outcome, CRM Record ID.

## Failed Operations

Fields: Error ID, Timestamp, Workflow, Node, Error Type, Error Message, Input Data, Status, Retry Count, Resolution Notes.

## Sources

Fields: Source Name, Source Type, Trust Level, Last Crawl Date, Records Discovered, Average ICP Match.
